# A Story as Old as Time

Thornvale — a top-down 2D MMORPG. Enter the Vale.

Play: https://vale-as-old-as-time.vercel.app

Six classes, Tibia-style skills, eight continents, shops, ships, gates, procedural hollows, and named folk.

## Local development

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

### Controls

- **WASD** or **Arrow keys** — move
- Camera follows the player on a seeded starter map

### Builds

```bash
npm run build        # Vercel / main site → dist/
npm run build:itch   # itch.io HTML5 pack → dist-itch/
```

## Theme

Background `#0c0d0b`, fonts Cinzel + Figtree.
